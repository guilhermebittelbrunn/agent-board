Comece pelo seu primeiro board

Cada board aponta para um repositório do GitHub. São três passos: os dois primeiros acontecem no GitHub e no repositório, o último aqui.

  1. 1
    Instale o GitHub App do boardAinda não instalado Ele deixa o board ler o board.yml e as specs, conferir a permissão de cada membro e abrir as PRs. Instale na sua conta ou na organização, escolhendo os repositórios.
    Instalar no GitHub
  2. 2
    Aplique o kit no repositório O kit cria o .kanban/board.yml e a regra do modo board. Rode numa branch de feature, revise e abra a PR.
    node kit/apply.mjs ../meu-repositorio Copiar
  3. 3
    Crie o board Escolha o repositório. O board lê o board.yml na branch base, mostra o que estiver errado e monta as colunas.
    Novo board Libera depois do passo 1
