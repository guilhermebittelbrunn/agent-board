O que cada papel pode fazer

Leitor Vê o board, os cards, os ciclos e os relatórios. Comenta. Exige read no GitHub
Operador Escreve, descobre e aprova specs, arrasta cards e roda ciclos com a própria credencial. Exige write no GitHub
Mantenedor Convida e remove membros, edita o ciclo agendado e os limites das colunas. Exige maintain no GitHub
Dono Tudo, mais a API key do board, a aprovação de planos e excluir o board. Exige admin no GitHub
